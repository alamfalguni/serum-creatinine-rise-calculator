Serum Creatinine 30% Rise Calculator

For rapid use in primary healthcare. The calculator accepts mg/dL or µmol/L and automatically converts the units when required.
30% threshold = Baseline serum creatinine × 1.30
A percentage rise is independent of the unit when both measurements use the same unit. If the reports use different units, this calculator converts them automatically. Conversion used: 1 mg/dL = 88.4 µmol/L.
This tool supports protocol-based assessment and does not replace clinical judgment.
